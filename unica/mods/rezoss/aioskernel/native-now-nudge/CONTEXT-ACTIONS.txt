Now Nudge photo/calendar parameter adapter -- 2026-10-15

Root cause and scope
--------------------
The active paradigm/semanticsearch/SemanticSearchCore.apk/0001 patch disables
incompatible donor QNN entrypoints. Its MT5ModelJni.inference returns empty
text. On the tested phone, benign photo and calendar requests passed the real
SBert intent gate but stock recall_action returned Unsafe for both. Do not
remove that native bypass: the donor neural graphs remain incompatible.

Patch 0005 delegates recognized requests to NativeContextActions after the
original RecallProvider intent/safety gate. ContextActionParser is a bounded
English text parser, not a reconstructed Samsung MT5 model. It consumes the
last incoming conversation turn or supplied screen text. Unsupported inputs,
disabled settings and errors fall through to the existing SSCO implementation.
It rejects self replies, negation, ambiguous event times and untitled events.
No arbitrary screenshot/pixel recognition, OCR or new screen capture is added.

Samsung still performs actual Gallery search, media action replacement, date
resolution, URI encryption, action rendering and user-reviewed execution.
No media is automatically sent and no event is automatically inserted.
View Calendar opens a date; it does not calculate availability/free-busy.
This does not restore general MT5, semantic embeddings, LVM or Gauss inference.

Build and activation
--------------------
customize.sh applies 0005-0006 after existing native patches 0001-0004 only in the
native mode. build_client_helper.sh and build_candidate.sh compile all maintained
client Java sources into DEX17. Register counts and original control flow are
preserved. No smali under firmware or generated target output is edited.

The context adapter is explicitly opt-in, default off on a fresh installation:
  /mnt/c/platform-tools/adb.exe shell settings put global rezoss_now_nudge_context_actions 1
Existing rezoss_now_nudge_native must also be 1. Existing user setting 0 is
respected. The boot script does not enable this experimental setting.
Disable immediately without replacing APKs:
  /mnt/c/platform-tools/adb.exe shell settings put global rezoss_now_nudge_context_actions 0

Incremental offline candidate from exact installed timeout-fix APK:
  source buildenv.sh dm3q
  bash unica/mods/rezoss/aioskernel/native-now-nudge/build_context_candidate.sh \
    out/archived/NowNudge_V73_TimeoutFix_20261015/SmartSuggestions-timeout-fix.apk \
    /tmp/SmartSuggestions-context-actions-new.apk
This script refuses other baseline hashes and existing output files. It only
replaces classes15.dex and classes17.dex; signatures are regenerated with the
selected platform key. It does not install or activate anything.
