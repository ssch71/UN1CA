OfflineLanguageModel on this phone embeds SDK 1.4.46. It automatically selects
the external service after numeric version comparison. Its initialization
profile must load/validate the replacement engine before contextual_reply can
be selected. Inference is rejected while only initialization is selected.
Samsung safety_check, VIT, LLMV, LVM, MT5 and semantic requests are not supported.
Do not advertise a Samsung Gauss model or Samsung adapter as loaded.

Probe: build_probe.sh emits an optional local instrumentation APK. Its Binder
mode validates real Samsung Proxy/Parcelable serialization across processes,
preload, token counting, completion, cancellation and unload. SCS testing must
run inside the real Samsung client because its service requires the Samsung
signature permission. The Probe.runInApp diagnostic is suitable for a temporary
REA/Frida call. No credentials are copied; original getAppInfo creates AppInfo.

The native runner is one bounded subprocess per request, not a persistent HTTP
server. It exits on completion, cancellation, client death or timeout. Battery
improvement is not established without a controlled comparison. This model has
1024 total tokens and uneven multilingual/three-reply quality.

Final candidate: backend POC6, frontend POC5. Apply frontend patches 0001,
0002 and 0003 in order; build_candidate.sh compiles NativeReplyBridge into
an additional DEX. The helper returns actual parsed replies to notification
callbacks and strips list markers/quotes. Existing user and conversation gates
remain in Samsung code. PromptAdapter translates the known contextual-reply
template while preserving dialogue, language and recall records.

Device prerequisite: this ROM already has Samsung AI Core/SCS and the full
OfflineLanguageModel 4.0.01.24 (400124010). Its package/assets are still needed
by Samsung's frontend, although its donor weights are not executed by this
backend. The bundle does not contain that package. APK signatures must match
the tested ROM. This minimal AIOS APK is not a stock replacement with its
backend flag disabled. Do not enable it by default in ROM customize scripts.

This is a data-APK install bundle, not a recovery-flashable ZIP. It has not been
validated as a clean full-ROM build or after an intentional reboot. The local
handler diagnostic exercises genuine Samsung code and callbacks but does not
prove a real messaging-app keyboard notification interaction. Reply quality,
multilingual behavior and safety-check support remain incomplete.
