Numerical diagnosis and fixes
----------------------------
1. The export uses a 20-byte ExecuTorch context header. Current upstream expects
   256 bytes, causing QNN 30010 when it receives a pointer into the payload.
   Exact payload-length validation selects the legacy offset.
2. The exported attention mask is [1, AR, 1024]. Current upstream assumes
   [1, 1, AR, context]. The unchecked old indexing caused excess allocation.
   Rank/dimension validation now handles both forms before allocating buffers.
3. The PTE declares FP32 mask/cache/logits tensors although its embedded decoder
   exposes UFixed16 at those endpoints. Raw pointer binding produced nonfinite
   floating-point logits and gibberish. Opt-in scale/offset quantization and
   dequantization at the delegate boundary restores valid results.

Offline numerical reference uses official source weights on the host CPU:
  Token-1 embedding maximum absolute difference: 3.8430095e-05; cosine 1.0.
  Decoder first-step logits correlation: 0.99797293; MAE 0.17230603.
  Decoder first two predicted IDs agree: 49189, 49153. All converted logits finite.
  Vision features cosine with reference: 0.7759886, MAE 2.3002934.
  Source model captions the cat correctly: "In the image we can see a cat walking
  on the snow." The quantized encoder/export quality gap remains unresolved.
