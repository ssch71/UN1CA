Ask Ai — PrivateLM handoff

Ask Ai launches com.orailnoor.privatelm, packaged independently in
unica/mods/privatelm using the original upstream-signed release APK.
PrivateLM owns chat history, model selection, inference, cloud configuration,
attachments and image generation. Models/API credentials are not bundled.
Now Nudge, notification summaries and Call Screening keep their ROM backend.

Analyze logs and Explain setup results retain collection, redaction, bounded
section selection, editable five-line expandable previews and explicit review.
Copy and open PrivateLM copies ONLY reviewed selected sections plus diagnostic
instructions to a sensitive clipboard, then opens the app. The user pastes into
a new chat, reviews the local/cloud provider, and explicitly sends there.
Settings neither invokes inference nor asserts a PrivateLM model is ready.
The upstream release does not implement incoming text/file sharing; no automatic
chat draft or attachment handoff is claimed. Redaction may miss private data.
The original log stays in Troubleshooting; nothing copies on cancel or if the
app is missing. The clipboard remains subject to Android clipboard policy.

The old AskAiChat/AiClient source remains for rollback, but the menu and reviewed
diagnostic flows no longer call it. No AIOS rebuild is needed for this change.

Host verification covers Java/D8 compilation, smali assembly, strict patch
application and APK/chunk hashes/signatures. Full ROM packaging, flashed app
launch, rendering, model setup/inference and image generation require device
validation. No device install, reboot, build of the full ROM or push is implied.
